# 📊 Customer Behavior Analysis Dashboard

An end-to-end data project analyzing 3,900 rows of retail shopping data to uncover consumer trends, subscription behavior, and revenue distribution.

## 🛠️ Tech Stack Used
* **Python (Pandas):** For data inspection, cleaning, and handling null values.
* **PostgreSQL:** For querying relational database metrics and customer segments.
* **Data Visualization:** Built an interactive dashboard tracking key behavioral KPIs.

## 📈 Key Project Insights
* **The Baseline:** Analyzed 3,900 unique customer transactions with an average order value of **$59.76** and a **3.75** average product rating.
* **Category Leaders:** **Clothing** represents the highest driving factor for both overall sales volume and total revenue metrics.
* **Demographics:** The **20-29 age bracket** represents our highest spending consumer segment across categories.

## 📂 Repository Structure
* `Customer_shopping_analysis.csv` - The raw data file.
* `customer_behavior_pipeline.ipynb` - Python notebook cleaning and sending data to SQL.
* `customer_analysis_queries.sql` - Optimized SQL analysis scripts.
